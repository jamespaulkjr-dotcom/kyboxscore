# KY BOXSCORE Logo Package

Repo-ready PNG assets split from the approved logo package sheet.

## Recommended usage
- `ky-boxscore-primary.png` — primary stacked logo.
- `ky-boxscore-lockup-wide.png` — wide header/hero lockup.
- `ky-boxscore-wordmark-horizontal.png` — navigation/header wordmark.
- `ky-boxscore-scoreboard.png` — standalone scoreboard mark.
- `ky-boxscore-badge-round.png` — social/profile badge.
- `ky-boxscore-kentucky-badge.png` — Kentucky-specific secondary badge.
- `ky-boxscore-score-strip.png` — compact score-strip graphic.
- `ky-boxscore-icon-*-512.png` — app/favicon/social icon candidates.

## Brand colors
- Navy: `#00152E`
- Gold: `#FCB526`
- White: `#FEFEFE`

## Important production note
These files are clean raster extractions from the approved AI-generated concept sheet, not true vector master artwork. They are appropriate for web mockups and implementation. For print, signage, or perfect SVG scaling, the final selected lockup should be manually redrawn/vectorized rather than auto-traced.
